         # Interview Mentor AI

## Overview

Interview Mentor AI is an AI-powered web application designed to help university students, fresh graduates, and internship seekers practice interviews confidently. The application generates role-specific interview questions, evaluates user responses using Google Gemini AI, and provides personalized feedback to improve interview performance.

## Problem It Solves

Many students struggle to prepare for interviews because they lack realistic practice opportunities and personalized feedback.

Interview Mentor AI provides an interactive interview practice environment where users can receive instant AI-powered evaluations, helping them improve their communication, confidence, and interview skills before real interviews.

# AI Feature

Interview Mentor AI uses Google Gemini to power two major AI features:

### 1. Interview Question Generation

The AI generates realistic interview questions based on:

- Job Role
- Interview Type
- Experience Level

### 2. Answer Evaluation

The AI evaluates the user's answer and provides:

- Overall score
- Strengths
- Areas for improvement
- Improved answer
- Follow-up interview question
- Interview summary
- Personalized interview tips

The prompts were carefully designed to generate dynamic and role-specific responses instead of generic feedback.

# How to Run the Project

1. Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Install dependencies.

```bash
npm install
```

3. Create a `.env` file and add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

4. Start the application.

```bash
npm run dev
```
